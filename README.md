## Technical foundation

- Next.js / TypeScript and Supabase.
- Platform areas include curated business assets, controlled access to buyer diligence material and transaction/checkout foundations.
- The status of live payment gateways, financial settlement, file-entitlement access and ownership transfer must be verified with dedicated Production acceptance tests before calling those flows operational.

## Development

```bash
npm ci
npm run build
npm run dev
```

Keep secrets in protected deployment environments, not in Git or public browser configuration. Keep buyer/owner data out of public previews and sale listings.

## Sale-grade handover

For each listed asset, specify what transfers: repository snapshot, intellectual-property rights, domains, licenses, documentation, migrations and permitted data. Payment completion is not a substitute for proof of ownership or safe, independent deployment.
